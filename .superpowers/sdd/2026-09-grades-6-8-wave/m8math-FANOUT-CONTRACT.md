## Answer-position balance — a hard rule (DF-1)
The Grade 7 wave measured a defect (DF-1) where correct answers clustered in particular MCQ choice slots across the bank — a pattern a student can learn to exploit without knowing any math. This course fixes it with a deterministic placement rule, not luck or spot-checking.

Your lesson has exactly two MCQ `try_yourself` items (the numeric one is exempt — there is no "position" to balance for a typed answer). For a lesson in unit `u`, topic `t` (the same `<u>` and `<t>` as your `metadata.cedTopic`), indexing choices a-b-c-d as 0-1-2-3:
- the FIRST MCQ item's correct choice sits at index `(u + t) mod 4`
- the SECOND MCQ item's correct choice sits at index `(u + t + 2) mod 4`

**These indices are different for every row — recompute them for YOUR unit and topic. Do not reuse a number from any example below.** Two contrasting rows, so the topic-dependence is visible rather than asserted:
- Unit 2, topic 1 (`product-quotient-and-power-of-a-power-rules`) → `(2 + 1) mod 4 = 3`, so the first MCQ's correct choice is index 3, letter **d**. `(2 + 1 + 2) mod 4 = 5 mod 4 = 1`, so the second MCQ's correct choice is index 1, letter **b**.
- Unit 6, topic 3 (`comparing-functions-in-different-representations`) → `(6 + 3) mod 4 = 9 mod 4 = 1`, so the first MCQ's correct choice is index 1, letter **b**. `(6 + 3 + 2) mod 4 = 11 mod 4 = 3`, so the second MCQ's correct choice is index 3, letter **d**.

Same formula, different row, different answer — d-then-b for one row, b-then-d for the other. Applied across all 40 lessons and 80 MCQ items, this places exactly 20 correct answers in each of the four positions — flat by construction, not by chance.

**Build the item with its key already in the required slot. Never write the item with the key wherever feels natural and then permute the `choices` array afterward.** This is exactly how the Grade 7 wave broke itself: a post-hoc permutation left separator commas attached to the wrong entries and produced undefined array holes that only `tsc` caught downstream, and separately, any `hints` text that names a choice by letter ("choice C is a trap because...") silently goes stale the moment the array is reordered out from under it. Write your distractors directly into the position the formula requires, in the same pass you write the correct choice — there is no safe way to write-then-reorder.

## Correctness — the one unrecoverable defect
**Every numeric answer must be arithmetically correct and independently checkable.** For every worked example and every `try_yourself`, actually compute the answer before you write it down; do not eyeball it. Where the exemplar convention shows a "check by working backward" step (substitute the solution into BOTH sides, multiply the fraction back out to the repeating decimal, square the estimate, apply the inverse coordinate rule, plug the pair into both equations of the system), include the equivalent check for your own item — it is not decoration, it is how a fourteen-year-old learns to catch their own mistake.
**Every MCQ distractor must be a real, nameable student error** — adding the exponents when multiplying powers with the same base, reading a negative exponent as a negative number, putting run over rise, dropping the (1/3) from the cone formula or using the diameter where the radius belongs, rotating clockwise when the rule is counterclockwise, moving a term across the equals sign without changing its sign, treating a repeated OUTPUT as what breaks a function, reading a same-side interior pair as equal. **Do not invent a rule to make an item work.** If you assert a mathematical fact (a property, a conversion factor, a formula, a coordinate rule), it must be true.
