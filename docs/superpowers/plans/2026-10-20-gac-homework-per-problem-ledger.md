Rulings (pre-flight):
- Ruling R1: label provenance = per-label check, not maximal-run membership. Normalise (collapse whitespace, unicode minus→-, ° kept, strip trailing period). A label passes if (a) it is a bare identifier/point name (letters, ≤3 chars, optional prime) that appears as a whole word in the text; or (b) a bare value (number, optionally with units or °) that appears in the text; or (c) `NAME <op> VALUE` where NAME appears in the text followed within ≤4 words by VALUE (so "AD = 6" and "AD is 6" pass; "DB = 9" fails because DB is followed by x). — why: the plan's rule as written can never match; spec §5a says "every label appears verbatim in the problem text or figure description (no computed lengths, no answers)" — cost if wrong: a good figure dropped to unverified, or a computed label slipping through when its value sits right after the name in the text.
